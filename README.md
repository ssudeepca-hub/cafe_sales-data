📊 Project Overview

The Cafe Sales Dashboard is an interactive business intelligence project developed using Microsoft Power BI.
It analyzes café sales data to uncover patterns in revenue, customer behavior, and product performance. The dashboard helps stakeholders make informed decisions through visual insights and real-time filtering.

📌 Key Metrics Displayed
Total Revenue – Overall sales generated
Total Orders – Number of transactions
Net Profit – Profit after deducting costs
Profit Margin – Percentage of profit earned
Quantity Sold – Total items sold
🚀 Dashboard Features
Interactive KPI cards for quick insights
Sales breakdown by category (Coffee, Desserts, Snacks)
Daily sales trend analysis (line chart)
Item-wise quantity and profit comparison
Customer segmentation (New vs Returning)
Gender-based analysis
Dynamic filters (Category, Date, Customer Type, Gender)
🛠️ Tools and Technologies Used
Microsoft Power BI Desktop
DAX (Data Analysis Expressions) for calculations
Data modeling techniques
Data visualization tools
🔄 Steps Followed
Data Collection – Gathered café sales dataset
Data Cleaning – Removed duplicates, handled missing values
Data Transformation – Structured data into usable format
Data Modeling – Created relationships between tables
DAX Calculations – Built KPIs like profit and revenue
Dashboard Design – Created interactive visuals
Testing & Validation – Ensured accuracy of insights
📈 Key Insights
Coffee category generates the highest revenue
A few top-selling items contribute most of the profit
Sales fluctuate across different days
Returning customers contribute significantly to revenue
Profit margin varies across product categories
📌 How to Use
Download or clone the repository
Open the .pbix file in Power BI Desktop
Use filters (Category, Date, Customer Type, Gender)
Interact with charts to explore insights
